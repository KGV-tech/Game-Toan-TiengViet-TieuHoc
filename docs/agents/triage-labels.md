# Triage labels

Bộ skill Matt Pocock dùng năm vai trò triage chuẩn; repo dùng đúng tên mặc định:

| Vai trò | Label GitHub | Ý nghĩa |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Chờ phân loại |
| `needs-info` | `needs-info` | Chờ bổ sung thông tin |
| `ready-for-agent` | `ready-for-agent` | Đủ thông tin để agent xử lý |
| `ready-for-human` | `ready-for-human` | Cần người dùng quyết định/thực hiện |
| `wontfix` | `wontfix` | Không thực hiện |
