# Domain docs

Repo này là single-context. Trước khi thay đổi domain hoặc luồng gameplay, đọc:

- `docs/PROJECT_CONTEXT.md` — kiến trúc game và giới hạn an toàn.
- `docs/LESSON_HIERARCHY_SPEC.md` — quan hệ Chủ đề → Bài học.
- `docs/templates/TEMPLATE_SYSTEM.md` — contract và lộ trình Template.
- `docs/adr/` nếu thư mục này có quyết định liên quan.

Khi đặt tên issue, test, module hoặc đề xuất refactor, ưu tiên thuật ngữ trong các
tài liệu trên. Nếu một khái niệm chưa có định nghĩa thống nhất, dùng
`domain-modeling` trước khi đổi vocabulary trong nhiều file.
