# Issue tracker: GitHub

Issues và Pull Requests của repo nằm trên GitHub:

`https://github.com/KGV-tech/Game-Toan-TiengViet-TieuHoc`

Các skill `to-spec`, `to-tickets`, `triage` và `wayfinder` nên dùng GitHub Issues
cho ticket, map và trạng thái công việc. Khi GitHub CLI đã đăng nhập, dùng các lệnh
`gh issue view`, `gh issue list`, `gh issue create`, `gh issue comment` và
`gh issue edit`. Nếu CLI chưa đăng nhập, chỉ đọc thông tin local và báo checkpoint;
không tự tạo issue bằng cách khác.

PR không được xem là request surface cho triage bên ngoài; PR là nơi review thay đổi
đã được triển khai.
